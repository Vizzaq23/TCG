# Feature 9/365 — Wanted Poster shelf bounty

**Status:** Implemented  
**Date:** 2026-08-11  

## What it does

Every public profile shows a playful **Wanted** poster with:

- Shelf bounty (berries — not real money)
- Rank title (East Blue Rookie → Yonko-Class Shelf)
- Chips for unique cards, rare hits, graded slabs, followers

Computed from existing public shelf + follower count. No migration.

## Why

Gives each collector a One Piece–flavored reputation identity, different from Daily Treasure (which spotlights one card).
